# Student Login Portal

A simple Flask-based Student Login Portal with validation.

## Features

- Student Login Form
- Input Validation
  - No empty fields
  - Password minimum 6 characters
  - Roll number must contain only numbers
- Success Page
- Error Handling

---

## Technologies Used

- Python
- Flask
- HTML
